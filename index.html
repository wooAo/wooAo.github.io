Retail Space Digitization / 3D Reconstruction

优融三维视觉采集与空间理解系统

丝融二维货架视觉系统已能支撑大规模采集，但在高货架、窄通道、地堆等场景中仍受物理空间、视角覆盖和尺度恢复限制。优融将系统升级为零售空间数字化视觉系统，不只输出货架拼图，还恢复三维结构和真实尺寸。

  • 作为项目Owner负责技术路线选择、模型评估、推理部署、数据Pipeline、采集策略、三维几何后处理和尺寸恢复。
  • 采用Depth Anything 3主链路 + MASt3R失败兜底，利用metric scale相机位姿和点云拟合货架主平面，结合相机内外参求解Homography并生成拼图。
  • 2026年7月底在中国CNPG国内产线全量上线，单月约1万次货架采集拼接任务；货架宽度平均测量误差≤5%，核心业务指标相比丝融提升约1-2个百分点。

Retail Vision SDK / App + Cloud

丝融零售货架视觉采集SDK

面向大规模零售货架采集场景，将目标从“能拼出图”升级为“可支撑下游识别与陈列计算的稳定视觉采集SDK”，覆盖端侧采集、特征匹配、云端重拼、质量评估和失败数据闭环。

  • 设计App端视频采集、同步关键帧抽取、子线程端侧拼接、拼接状态回调和云端重拼架构。
  • 采用SuperPoint替代SIFT、LightGlue替代暴力匹配，结合全局检索、局部匹配、基础矩阵外点过滤与Homography求解，提升重复纹理场景匹配鲁棒性。
  • 支撑美国、加拿大、中国市场长期运行，月均10万+货架采集拼接任务；全年QC通过率提升约10%，访店时间降低约10%。
Robot Vision / ROS2

Kiwi风电叶片内检机器人视觉采集系统

面向风电叶片内腔狭窄、暗光、光照不可控的现场环境，将拍摄问题抽象为覆盖率、图像质量、设备协同和现场稳定性的系统工程问题，选择半画幅相机、闪光灯、舵机和ROS2软件触发方案。

  • 负责camera driver/controller、servo driver/controller等ROS2节点，相机通过热靴触发闪光灯，拍照成功回调触发下一次舵机动作。
  • 基于叶片内腔四面结构设计双相机分工，并根据叶片结构参数、相机FOV和圆锥体几何假设计算拍摄间隔、舵机角度和小车速度。
  • 现场参与90台风机实操交付，单风机约3小时、2000+图片；系统量产约百台，并交付第三方独立操作。
